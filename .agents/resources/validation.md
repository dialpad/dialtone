# Dialtone Validation Map

The one map of checks per path, shared by `validate`, `pr-prep`, `component-work` and PR workflows. Prefer focused checks first, then broader ones when an API or downstream package changed. Run from the repo root. `pr-prep`'s `references/local-gates.md` says how to read the results.

## Writes

Each check says whether it changes files, checked by comparing `git status --porcelain` before and after a run.

- `no`: leaves tracked and untracked files unchanged.
- `output`: writes only git-ignored build output.
- `keywords`: rewrites tracked `packages/dialtone-icons/src/keywords-*.json` when a source SVG has no entry. Anything that depends on `dialtone-icons:build` inherits this: `dialtone-vue:test`, `dialtone-vue:build`, `dialtone-combinator:test`, `dialtone-docs:build`, `dialtone-docs:test` and the builds below them.
- `themes`: depends on `dialtone-tokens:build`, which runs `git clean -fx themes/` and deletes untracked files under `packages/dialtone-tokens/themes/`. This covers `dialtone-css:build`, `dialtone-query-core:build`, the CLI and MCP builds, and the documentation build.
- `fix`: the script runs `--fix` and rewrites source.
- `?`: not verified; treat as writing.

Report-only runs only `no` and `output` rows. Skip the rest and say why.

`pnpm` scripts can rewrite `pnpm-lock.yaml` when `node_modules` is stale: pnpm 11 installs first, and this was seen on a clean checkout. Set `pnpm_config_verify_deps_before_run=false` for report-only runs and check `git status` afterwards.

Stylelint with fixing off, from the repo root:

```sh

echo "module.exports = { ...require('$PWD/stylelint.config.cjs'), fix: false };" > "$cfg"
pnpm --dir packages/dialtone-css exec stylelint --config "$cfg" 'lib/build/less/**/*.less'
```

## Done when

- Every changed area has at least one focused check selected or an explicit reason it was skipped.
- Cross-package changes include downstream build or test coverage where the package graph indicates risk.
- Output is summarized with pass, fail or skip status and the exact commands.
