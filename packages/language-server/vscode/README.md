# Dialtone VSCode Extension

Dialtone Intellisense enhances the Dialtone development experience by providing Visual Studio Code users with autocomplete features.

## Features

### Autocomplete

Inteligent suggestion for component names, props and values, as well as [Design Tokens](https://dialtone.dialpad.com/tokens/)

### Hover Preview

Coming soon.

## Troubleshooting

If you’re having issues getting the Dialtone IntelliSense features to activate:

- Take a look at the language server output by running the `Dialtone: Show Output` command from the command palette. This may show errors that are preventing the extension from activating.
