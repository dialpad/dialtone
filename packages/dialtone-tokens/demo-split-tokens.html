How It Works

The new architecture splits tokens into three categories:

  1. Core Tokens (31KB) - Typography, spacing, sizing - loaded once
  2. Component Core (31KB) - Non-color component tokens - loaded once
  3. Brand Colors (88KB) - Both light and dark colors in one file

Example CSS Structure

/* Light mode colors in :root */
:root {
  color-scheme: light;
  --dt-color-surface-primary: #FFFFFF;
  --dt-color-foreground-primary: #000000;
  /* ... more light colors ... */
}

/* Dark mode colors with selector */
[data-dt-mode="dark"] {
  color-scheme: dark;
  --dt-color-surface-primary: #1C1C1C;
  --dt-color-foreground-primary: #FFFFFF;
  /* ... more dark colors ... */
}
