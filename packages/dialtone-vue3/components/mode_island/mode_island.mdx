# Mode Island

Creates isolated sections with independent color modes (light/dark). Override root theme for specific UI sections while maintaining contrast inheritance.

## Usage

Use mode islands to:
- Force sections to light or dark mode
- Invert current theme for emphasis/hierarchy
- Build components with consistent appearance regardless of user theme
- Create nested theme contexts

## Basic Example

```vue
<template>
  <!-- Always inverts the parent/root mode -->
  <dt-mode-island>
    <p>This content uses the inverted mode</p>
  </dt-mode-island>

  <!-- Always light mode -->
  <dt-mode-island mode="light">
    <p>This content is always in light mode</p>
  </dt-mode-island>

  <!-- Always dark mode -->
  <dt-mode-island mode="dark">
    <p>This content is always in dark mode</p>
  </dt-mode-island>
</template>
```

## Props

### `mode`
Controls the color mode of the island.

- **Type**: `String`
- **Default**: `'inverted'`
- **Values**:
  - `'inverted'`: Opposite of the parent mode or root theme
  - `'light'`: Always light mode
  - `'dark'`: Always dark mode

### `as`
Specifies the HTML element to render.

- **Type**: `String`
- **Default**: `'div'`
- **Common values**: `'div'`, `'section'`, `'article'`, `'nav'`, `'aside'`, `'header'`, `'footer'`, `'main'`

## Features

### Nested Mode Islands
Nest islands to create theme hierarchies. `mode="inverted"` detects parent island and inverts accordingly.

```vue
<dt-mode-island mode="dark">
  <!-- dark -->
  <dt-mode-island mode="inverted">
    <!-- light (inverted from parent) -->
    <dt-mode-island mode="inverted">
      <!-- dark again -->
    </dt-mode-island>
  </dt-mode-island>
</dt-mode-island>
```

### Reactive Mode Updates
**Inverted islands auto-react to parent/root theme changes.** Component watches root element and parent islands, flipping instantly when themes change—no page refresh needed.

When user switches light ↔ dark, all inverted islands flip to maintain opposite mode. Works with `mode="system"` and respects OS theme preference changes.

**Note**: Inverted islands get `data-mode-island-inverted` attribute (useful for styling/debugging).

### Contrast Inheritance
Auto-inherits `data-dt-contrast` from root element, updates reactively. High contrast mode works correctly within islands.

### Brand Protection
`data-dt-brand` prohibited on islands—maintains brand consistency. Set brand at root level only. Attempting to set throws error.

## Accessibility

Purely visual—no semantic HTML impact. Maintains contrast ratios, supports high contrast mode via auto contrast inheritance.

## Best Practices

1. **Use sparingly**: Intentional use for specific needs, not general theming
2. **Respect user preference**: Use explicit modes only when functionally necessary
3. **Test both modes**: Always test in light and dark root themes
4. **Maintain readability**: Content must remain readable when inverted
5. **Avoid deep nesting**: Keep hierarchy shallow for maintainability
