# Contact Info

<Subtitle>
  A contact information is an component that can be used to represent individual or group contact.
</Subtitle>

## Base Style

The contact information component has 4 slots that can be used for the most common use cases,
**header**, **subtitle**, **end** and **blockEnd** slot.

The **header** slot can be used to display html content or Vue component at header area.

The **subtitle** slot can be used to display content below the header slot. The slot has smaller
text size and lighter color than default slot.

The **end** slot works the same way, but its contents are placed to the end of the main slot.

The **blockEnd** slot can be used to display content below the subtitle slot.

Avatar is optional. When `avatarSrc` is specified, the avatar image will be displayed on the left and,
it is required to provide a value in `avatarFullName` to use in the alt attribute of the avatar image.
If `avatarSrc` is empty, it will fall back to `avatarFullName`, and user initials will be displayed
in avatar.

## Usage

### Import

```jsx
import { DtRecipeContactInfo } from '@dialpad/dialtone-vue';
```

### Contact with avatar

```html
<dt-recipe-contact-info
  :avatar-src="avatarSrc"
  presence="active"
  @avatar-click="onAvatarClick"
>
  <template #header>
    <div class="d-fs-200 d-fw-bold d-mr-50">
      Joseph Lumaban
    </div>
  </template>
  <template #subtitle>
    <dt-stack direction="row" align="center">
      <div class="d-fs-100 d-mt-25">
        +1 (415) 123-4567
      </div>
      <dt-icon name="check" size="100"
        class="d-fc-tertiary d-icon--size-100 d-va-text-bottom"
      />
    </dt-stack>
  </template>
  <template #blockEnd>
    <dt-stack direction="row" align="center" class="d-mt-n75">
      <div class="d-w-8px d-h-8px d-mr-50 d-bgc-magenta-200">
        &nbsp;
      </div>
      <div class="d-fs-100 d-mr-50">
        Aerolabs Support
      </div>
    </dt-stack>
  </template>
</dt-recipe-contact-info>
```
