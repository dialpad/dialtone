# Grouped Chip

<Subtitle>
  Grouped Chip is a format used to present related information such as callbar timers.
</Subtitle>

## Base Style

Grouped chip component has related info split in two combination chips. Common use cases represented
are split callbar timers showing call time and hold time on the left hand and right hand side respectively.

This component has 4 slots: **startIcon**, **startContent**, **endIcon** and **endContent** slot.

**startIcon** is used to display an icon that best represents the startContent.

**startContent** is used to display content and is placed on the start side.

**endIcon** is used to display an icon that best represents the endContent.

**endContent** is used to display content and is placed on the end side.

## Usage

### Import

```jsx
import { DtRecipeGroupedChip } from '@dialpad/dialtone-vue';
```

### Split Combination Chip showing both start and end side content.

```html
<dt-recipe-grouped-chip>
  <template #startIcon>
    <dt-icon name="clock" />
  </template>
  <template #startContent>
    <div>
      0.15
    </div>
  </template>
  <template #endIcon>
    <dt-icon name="pause" />
  </template>
  <template #endContent>
    <div>
      0.15
    </div>
  </template>
</dt-recipe-grouped-chip>
```
