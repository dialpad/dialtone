# Scrollbar directive

A custom scrollbar directive that wraps [OverlayScrollbars](https://kingsora.github.io/OverlayScrollbars/)
to provide styled, cross-browser-consistent scrollbars.

## Usage

Import `DtScrollbarDirective` from `@dialpad/dialtone-vue` and register it with
`app.use(DtScrollbarDirective)` on your Vue 3 application before mounting. Use
`v-dt-scrollbar` on the container. Load Dialtone CSS and the
`overlayscrollbars/overlayscrollbars.css` stylesheet. The container needs a single
child element for the viewport and a size constraint so its content can overflow.

```js
import { DtScrollbarDirective } from "@dialpad/dialtone-vue";
```

Register the directive on your application:

```js
app.use(DtScrollbarDirective);
```

### Default

The default public mode is `enter`: show on pointer entry and hide on pointer
leave. The directive maps this to OverlayScrollbars' internal `leave` mode.

```html
<div v-dt-scrollbar>
  <div>Scrollable content</div>
</div>
```

### Auto-hide modes

Control when the scrollbar hides using directive arguments:

Allowed public arguments are `always`, `enter` (default), `scroll`, and `move`.
`always` keeps the scrollbar visible; `scroll` and `move` auto-hide after
scrolling or pointer movement with a 1300ms delay. Unknown values fall back to
`enter`. OverlayScrollbars' internal `never` and `leave` names are not public
directive arguments. The directive does not read modifiers.

**Never auto-hide** — scrollbar is always visible

```html
<div v-dt-scrollbar:always>
  <div>Scrollable content</div>
</div>
```

**Hide on scroll** — scrollbar hides after scrolling stops (1300ms delay)

```html
<div v-dt-scrollbar:scroll>
  <div>Scrollable content</div>
</div>
```

### Important

The directive expects the scrollable content to be wrapped in a single child element,
which becomes the OverlayScrollbars viewport.

## Object configuration and cleanup

Bind an object with `showScrollbar`, `offset`, `blockClasses`, or `inlineClasses`.
`showScrollbar` takes precedence over the argument. `offset` supports logical
`blockStart`, `blockEnd`, `inlineStart`, and `inlineEnd`, plus `block` and `inline`
fallbacks; numbers become pixel lengths and strings are used as CSS lengths.
`blockClasses` and `inlineClasses` are space-separated class strings for the
vertical and horizontal scrollbars. Configuration updates apply to the existing
instance; unmounting destroys its OverlayScrollbars instance.

See the [Scrollbar page](https://dialtone.dialpad.com/components/scrollbar.html)
for complete styling and configuration examples.
