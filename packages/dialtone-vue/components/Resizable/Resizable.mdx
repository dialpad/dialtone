## Usage

### Import

```jsx
import {
  DtResizable,
  DtResizablePanel,
  DtResizableHandle,
} from '@dialpad/dialtone-vue';
```

### Basic Usage

```html
<dt-resizable>
  <dt-resizable-panel id="left">
    Left content
  </dt-resizable-panel>
  <dt-resizable-handle />
  <dt-resizable-panel id="right">
    Right content
  </dt-resizable-panel>
</dt-resizable>
```

### With Persistence

Use `storageKey` for localStorage, or `:storage` for Pinia/Vuex/custom backends.

```html
<!-- localStorage shorthand -->
<dt-resizable storage-key="my-layout">
  <dt-resizable-panel id="left">Left</dt-resizable-panel>
  <dt-resizable-handle />
  <dt-resizable-panel id="right">Right</dt-resizable-panel>
</dt-resizable>

<!-- Custom adapter (Pinia, Vuex, API, etc.) -->
<dt-resizable :storage="piniaAdapter">
  ...
</dt-resizable>
```

## Accessibility

### Keyboard Support

Each handle has `role="separator"` with `aria-orientation`, `aria-controls`, `aria-valuetext`, and value attributes. Handles are always focusable and follow the [W3C ARIA separator pattern](https://www.w3.org/WAI/ARIA/apg/patterns/windowsplitter/).

| Key | Action |
| --- | --- |
| Arrow keys | Resize by 8px |
| Shift + Arrow | Resize by 24px |
| Ctrl/Cmd + Arrow | Resize by 1px |
| Enter | Collapse/expand adjacent panel |
| Home | Set panel to minimum size |
| End | Set panel to maximum size |
| R | Reset adjacent panels |
| Escape | Remove focus from handle |

Double-clicking a handle resets adjacent panels to their initial sizes.
