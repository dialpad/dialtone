FormKit provides standardized fieldsets for complex settings and admin pages. It includes text inputs, textareas, and repeating multi-field variants designed for form-heavy interfaces.

## Overview

FormKit components simplify the creation of complex forms with:
- Consistent field layouts and spacing
- Built-in validation states
- Label and help text patterns
- Multi-field grouping
- Repeating field sections

## Key Components

### Input Components
- **Input Text Field**: Single-line text input with label and validation
- **Textarea Field**: Multi-line text input for longer content
- **Dropdown Field**: Select dropdown with search and filtering

### Field Groups
- **Field Row**: Horizontal arrangement of related fields
- **Repeating Field Group**: Dynamic add/remove field sections
- **Fieldset**: Grouped fields with section heading

## Installation

```bash
npm install @dialpad/formkit
```

```javascript
import "@dialpad/formkit/vue3/css";
import { DpInputTextField, DpDropdownField } from "@dialpad/formkit/vue3";
```
