title: What are UI Kits?
description: Learn what UI Kits are and how they help teams build consistent product experiences at Dialpad.
---

UI Kits are pre-built, composable collections of components and patterns designed for specific product experiences at Dialpad. While Dialtone provides the foundational design system — tokens, utilities, and base components — UI Kits build on top of Dialtone to deliver higher-level, domain-specific solutions.

## Why UI Kits?

Building product features often requires combining many base components into repeated patterns. UI Kits solve this by packaging these patterns into ready-to-use building blocks tailored to specific domains like chat, forms, analytics, and more.

## How they relate to Dialtone

- **Dialtone** provides the foundation: design tokens, CSS utilities, and base components (buttons, inputs, modals, etc.)
- **UI Kits** build on that foundation with domain-specific, higher-level components (chat bubbles, form wizards, call controls, etc.)
