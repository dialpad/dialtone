AnalyticsKit provides low-level D3.js visualization widgets for dashboards. It features dynamic charts, data tables, and metric summaries designed for analytics and reporting interfaces.

## Overview

AnalyticsKit components are designed for data visualization and analysis:
- Interactive charts powered by D3.js
- Responsive data tables with sorting and filtering
- Metric cards with trend indicators
- Dashboard layouts
- Export and sharing capabilities

## Planned Components

### Chart Components
- **Line Chart**: Time-series data visualization
- **Bar Chart**: Categorical data comparison
- **Pie Chart**: Proportional data display
- **Scatter Plot**: Correlation and distribution analysis

### Data Components
- **Data Table**: Sortable, filterable data grid
- **Metric Card**: Key metric display with trends
- **Dashboard Grid**: Responsive layout for multiple widgets

## Installation

```bash
npm install @dialpad/analyticskit
```

```javascript
import "@dialpad/analyticskit/vue3/css";
import { DpLineChart, DpDataTable } from "@dialpad/analyticskit/vue3";
```

## Status

AnalyticsKit is currently in the planning phase. Components and APIs are subject to change.
