ChatKit provides presentation components for the app conversation feed and chatbots. It includes message rows, composers, and action sheets designed specifically for messaging experiences.

## Overview

ChatKit components are built to handle the complexities of modern chat interfaces, including:
- Message threading and replies
- Rich media attachments
- User mentions and reactions
- Typing indicators
- Message composition

## Key Components

### Message Components
- **Message Row**: Displays individual messages with sender info, timestamps, and content
- **Message Thread**: Groups related messages in a thread view
- **Message Composer**: Rich text input for composing messages

### Action Components
- **Action Sheet**: Bottom sheet for message actions (reply, forward, delete)
- **Reaction Picker**: Emoji reaction selector

## Installation

```bash
npm install @dialpad/chatkit
```

```javascript
import "@dialpad/chatkit/vue3/css";
import { DpMessageRow, DpMessageComposer } from "@dialpad/chatkit/vue3";
```
