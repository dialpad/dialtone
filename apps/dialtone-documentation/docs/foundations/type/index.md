  <div class="d-d-grid d-g-600 d-g-cols1 md:d-g-cols2">
    <dt-stack gap="200">
      <h2 class="d-docsite--header-3 d-mbs-0">Season VF Sans</h2>
      <p class="d-docsite--paragraph">The typeface for everything in brand and marketing communications: headlines, display statements, stat numerals, eyebrows, body copy, buttons, and labels.</p>
    </dt-stack>
    <dt-stack gap="200">
      <h2 class="d-docsite--header-3 d-mbs-0">Season VF Mix</h2>
      <p class="d-docsite--paragraph">The serif axis of Season VF, built on the same character and proportions as Sans. Use it only for pull quotes and customer quotes. Never use Mix for headlines, stats, or body copy.</p>
    </dt-stack>
  </div>

    <div>
      <h2 class="d-docsite--header-3 d-mbs-0">Fallback</h2>
      <p class="d-docsite--paragraph">Where Season VF can't be installed (Google Docs, Google Slides, PowerPoint, and Keynote), use <strong>DM Sans</strong> throughout, including for quotes. DM Sans is the only approved fallback.</p>
    </div>

      <p class="d-docsite--paragraph">Product UI uses system fonts. The <code>expressive</code> font token (Season Mix) is reserved for limited in-product moments.</p>
