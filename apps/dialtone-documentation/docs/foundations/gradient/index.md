> [!WARNING] Legacy element
> Don't use the gradient in new brand or marketing work. For color, texture, energy, or an "AI is working" signal, use the [Resolve halftone](/foundations/halftone/).

## Approved uses

The gradient stays in the system for these uses only.

| Use | Guidance |
| --- | --- |
| App icon and AI marks | The gradient app icon (`Dialpad-Icon-Circle-Gradient`, `Dialpad-Icon-Tile-Gradient`) and Dialpad AI lockups are logo assets. Use the approved files as supplied. See [Our Icon](/foundations/brand/our-icon/). |
| Product UI | Gradient treatments that are part of product UI, such as the AI badge. See [Gradient in Product](/foundations/gradient/product.html). |
| AI type | AI-written words inside product UI can fade in on the AI type gradient, then settle to solid ink. Use the `gradient-in` mode of [Motion Text](/components/motion-text.html). Never use it on headlines. |
| Shipped work | Existing assets that already use the gradient can stay until they're refreshed. Replace the gradient with the halftone when you update them. |

## Don't

- Use the gradient as a page, section, hero, cover, slide, or banner background, or as a wash.
- Fill text with the gradient, including headlines and stat numerals.
- Apply it to shapes, borders, buttons, orbs, or glows.
- Recreate it from CSS color stops. Use the approved gradient files.

## Legacy assets

The light and dark gradient files remain in [Downloads](/downloads/#gradient) for maintaining shipped work.
