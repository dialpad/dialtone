DtStack is a layout component for flex-based layouts. It handles direction, alignment, justification, and gap through props instead of utility classes. This reduces class clutter and improves readability. DtStack already includes `display: flex`, so `d-d-flex` is redundant when using it.

## What's Changing

- **ESLint rules** now flag flex utilities on DtStack components
- **New ESLint rule** suggests DtStack for elements with `d-d-flex`
- **Migration tool** available via npx to automate conversion

## Quick Reference

| Flex Utility | DtStack Prop | Value |
|--------------|--------------|-------|
| `d-d-flex` | (not needed) | DtStack is already flex |
| `d-ai-center` | `align` | `"center"` |
| `d-ai-flex-start` | `align` | `"start"` |
| `d-ai-flex-end` | `align` | `"end"` |
| `d-ai-stretch` | `align` | `"stretch"` |
| `d-ai-baseline` | `align` | `"baseline"` |
| `d-jc-center` | `justify` | `"center"` |
| `d-jc-flex-start` | `justify` | `"start"` |
| `d-jc-flex-end` | `justify` | `"end"` |
| `d-jc-space-between` | `justify` | `"between"` |
| `d-jc-space-around` | `justify` | `"around"` |
| `d-jc-space-evenly` | `justify` | `"evenly"` |
| `d-fd-row` | `direction` | `"row"` |
| `d-fd-column` | `direction` | `"column"` |
| `d-fd-row-reverse` | `direction` | `"row-reverse"` |
| `d-fd-column-reverse` | `direction` | `"column-reverse"` |
| `d-g0` | `gap` | `"0"` |
| `d-g8` | `gap` | `"400"` |
| `d-g16` | `gap` | `"500"` |
| `d-g24` | `gap` | `"550"` |
| `d-g32` | `gap` | `"600"` |
| `d-g48` | `gap` | `"650"` |
| `d-g64` | `gap` | `"700"` |

## Keep as Classes

Some flex utilities have no DtStack prop equivalent. Keep them as classes on the component:

- `d-fw-wrap`, `d-fw-nowrap` (flex-wrap)
- `d-fl-grow1`, `d-fl-shrink0` (flex grow/shrink)
- `d-as-*` (align-self)
- `d-ac-*` (align-content)
- `d-g80` and larger gaps

**Example:**

```html
<dt-stack align="center" class="d-fw-wrap d-g96">
  <!-- children -->
</dt-stack>
```

## Using the Migration Tool

The migration tool scans Vue files for `d-d-flex` patterns and converts them to DtStack. It's included with `@dialpad/dialtone-css`.

### Preview Changes

```bash
npx dialtone-migrate-flex-to-stack --dry-run
```

### Target a Directory

```bash
npx dialtone-migrate-flex-to-stack --cwd ./src/components
```

### Apply All Changes

```bash
npx dialtone-migrate-flex-to-stack --yes
```

### Interactive Mode

```bash
npx dialtone-migrate-flex-to-stack
```

For each match, respond with:
- `y` or `yes`: Apply this change
- `n` or `no`: Skip this change
- `a` or `all`: Apply all remaining changes
- `q` or `quit`: Stop and save

### All Options

| Flag | Description |
|------|-------------|
| `--dry-run` | Show changes without applying |
| `--cwd <path>` | Set working directory |
| `--yes`, `-y` | Auto-apply all changes |
| `--help`, `-h` | Show help |

## Manual Migration

1. Find elements with `d-d-flex` class
2. Change the tag to `<dt-stack>`
3. Change closing tag to `</dt-stack>`
4. Convert classes to props using the table above
5. Keep non-convertible classes on the component
6. Remove `d-d-flex` (DtStack is already flex)

## Responsive Patterns

Responsive utilities like `md:d-ai-center` need manual migration. Use DtStack's responsive prop syntax:

**Before:**

```html
<div class="d-d-flex d-ai-start md:d-ai-center lg:d-jc-between">
```

**After:**

```html
<dt-stack
  :align="{ default: 'start', md: 'center' }"
  :justify="{ lg: 'between' }"
>
```

See the [Stack component docs](/components/stack.html) for more examples.
