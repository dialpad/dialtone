# Illustration

The Illustration component provides a set of images to provide context to your application

- **Status**: ready
- **Storybook**: https://dialtone.dialpad.com/vue/?path=/story/components-illustration--default
- **Keywords**: image, graphic, artwork, d-illustration, DtIllustration, dt-illustration, spot illustration, hero image

Check out our [illustration catalog](../foundations/illustrations.md), and our [brand section](../foundations/brand.md) for information on how to use this component.

## Vue API

### Props

| Name | Description | Type | Default |
| --- | --- | --- | --- |
| `size` | The size of the icon. | `string` | `'500'` |
| `name` | The icon name in kebab-case | `string` | `''` |
| `ariaLabel` | The label of the icon as read out by a screen-reader. Leave this unset if your icon is purely presentational | `string` | `''` |
