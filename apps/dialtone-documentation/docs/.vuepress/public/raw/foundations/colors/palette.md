# Color Palette

- **Keywords**: swatches,color tokens,color system

| neutral transparent | `var(--dt-color-neutral-transparent)` | `d-fc-neutral-transparent` |
| neutral white | `var(--dt-color-neutral-white)` | `d-fc-neutral-white` |
| placeholder — Text color for placeholder text within form elements. | `var(--dt-color-foreground-placeholder)` | `d-fc-placeholder` |
