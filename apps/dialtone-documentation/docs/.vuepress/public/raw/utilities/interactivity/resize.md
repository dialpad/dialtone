# Resize

Utilities for controlling the resize of an element.

- **Keywords**: resizable, drag to resize

## Usage

```html
<div class="d-r-both">...</div>
<div class="d-r-horizontal">...</div>
<div class="d-r-vertical">...</div>
<div class="d-r-none">...</div>
```

## Classes

| Class | Output |
| --- | --- |
| `d-r-block` | resize: block !important |
| `d-r-both` | resize: both !important |
| `d-r-inline` | resize: inline !important |
| `d-r-none` | resize: none !important |
